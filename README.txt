Analysis scripts for executive function task performance, timed subtraction, and academic achievement.
Run R scripts from the extracted root directory. They expect an authorized local copy of data/data_analysis.xlsx (Sheet1). See each script for package dependencies. Run SEM-table4-boot-full.R for Table 4, SEM-downstream.R for Table 5 and the joint model, SEM-crossdomain-tost-std.R for standardized contrasts, and SEM-invariance-final.R for the original sex-group analyses. The latter extracts individual path contrasts from its configural fit. Run code/check_partial_scalar.R for the additional check of path differences in the partial-scalar model, using the full parameter covariance matrix. The Python notebook draws figures from summary estimates. The forest plot labels intervals as BCa in the original plotting code, while the statistical script computes percentile intervals.
